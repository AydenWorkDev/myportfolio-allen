Basic Queuing

Academic Project | 2026

A school laboratory application that demonstrates a First-In, First-Out (FIFO) queue.

We built this for a practical task in a school laboratory. The application demonstrates the fundamental principles of data structures and process management using a First-In, First-Out (FIFO) logic model, where the first number added to the queue is the first one served.

Key features

  • Queue numbers served in the order they were issued (FIFO)
  • A "Now Serving" display for the current number
  • A cashier window that shows the position in the queue

Disclaimer!! This activity was developed as part of school activities for educational purposes only. All information and content are for academic purposes.
